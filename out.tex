\subsubsection*{\texorpdfstring{Church Booleans: encoding
\iMbox{\displaystyle \mathbb{B} = \{ \ \mathrm{true}, \ \mathrm{false} \ \}}}{Church Booleans: encoding }}

The Church Boolean encoding associates \ul{Kestrel} with
\iMbox{\mathrm{true}} and \ul{Kite} with \iMbox{\mathrm{false}}, so

\begin{itemize}
\tightlist
\item
  \iMbox{\displaystyle \mathrm{true} \equiv \mathrm{K} \equiv \lambda xy.x}
\item
  \iMbox{\displaystyle \mathrm{false} \equiv \mathrm{KI} \equiv \lambda xy.y}
\end{itemize}

\subsubsection*{\texorpdfstring{Basic logical operators:
\iMbox{\text{and}}, \iMbox{\text{or}}, \iMbox{\mathrm{not}},
\iMbox{\text{if} \ (p) \ \text{then} \ (x) \ \text{else} \ (y)}}{Basic logical operators: , , , }}

There are many \textit{other encodings}, but the advantage of \ul{Church
Booleans} is that \textbf{\textit{if-then-else}} becomes just
\ul{Identity}, so

\begin{itemize}
\tightlist
\item
  \iMbox{\text{if} \ (p) \ \text{then} \ (x) \ \text{else} \ (y) \ \equiv \ \mathrm{I} \ p \ x \ y \ \to_{\beta} \ p \ x \ y}
\end{itemize}

\ul{Cardinal} turns \ul{Kestrel} \textit{(\iMbox{\mathrm{true}})} into
\ul{Kite} \textit{(\iMbox{\mathrm{false}})} and vice-versa, so

\begin{itemize}
\tightlist
\item
  \iMbox{\mathrm{not} \equiv \mathrm{C} \equiv \lambda xyz.xzy}
\end{itemize}

\ul{Mockingbird} happens to function as \iMbox{\mathrm{or}}, where

\begin{itemize}
\tightlist
\item
  \iMbox{\displaystyle \mathrm{or} \ p \ q \equiv M \ p \ q \to_{\beta} p \ p \ q}
\item
  you can read it as \textit{`if \iMbox{p} is \iMbox{\mathrm{true}},
  pick \iMbox{p}, else pick \iMbox{q}'}
\end{itemize}

We can define \iMbox{\text{and}} in a similar manner

\begin{itemize}
\tightlist
\item
  \iMbox{\text{and} \equiv \lambda pq. pqp}
\item
  you can read it as *`if \iMbox{p} is \iMbox{\mathrm{false}}, pick
  \iMbox{p}, else pick \iMbox{q}'
\end{itemize}

\subsection*{\texorpdfstring{Arithmetic in
\ul{\iMbox{\lambda}-calculus}}{Arithmetic in -calculus}}

\subsubsection*{\texorpdfstring{Church numerals: encoding natural
numbers \iMbox{\mathbb{N}}}{Church numerals: encoding natural numbers }}

\textcolor{red}{\textbf{Pasted image 20241121184415.png}} The
\textbf{\textit{Church
numeral}}~\iMbox{\displaystyle n \equiv \lambda fx. \ \ f^{(n)} \ x} is
a function that

\begin{itemize}
\tightlist
\item
  takes a single-argument function \iMbox{f}, and
\item
  returns the \iMbox{n}-th composition of \iMbox{f},

  \begin{itemize}
  \tightlist
  \item
    i.e.~\iMbox{f} composed with itself \iMbox{n} times
  \item
    this is denoted with \iMbox{\displaystyle f^{(n)}}
  \end{itemize}
\end{itemize}

Such repeated compositions \iMbox{\displaystyle f^{(n)}} obey the laws
of exponents,

\begin{itemize}
\tightlist
\item
  therefore you can use them for \textbf{\textit{arithmetic}}
\end{itemize}

You can use \textbf{\textit{Church numeral}}~\iMbox{n} as an instruction
to `repeat \iMbox{n} times'

\begin{itemize}
\tightlist
\item
  e.g.~using \ul{pair functions} \iMbox{\mathrm{pair}} and
  \iMbox{\text{nil}} we can define a function
  \iMbox{\displaystyle \lambda nx. \ n \ (\mathrm{pair} \ x) \ \text{nil}},
  which

  \begin{itemize}
  \tightlist
  \item
    constructs a \ul{(linked) list} of \iMbox{n} elements \ul{all equal
    to }\iMbox{x},

    \begin{itemize}
    \tightlist
    \item
      i.e.~its bunch of \ul{nested pairs} in the form form
      \iMbox{\langle x, \ \langle x, \ \langle \dots, \ \langle x, \ \text{nil} \rangle \rangle \rangle \rangle}
    \end{itemize}
  \item
    by repeating \textit{`prepend another \iMbox{x} element'} \iMbox{n}
    times, starting from \iMbox{\text{nil}} element
  \end{itemize}
\end{itemize}

By varying \ul{what} is being repeated, and varying \ul{what argument}
that function being repeated \ul{is applied to}, much can be achieved

\subsubsection*{\texorpdfstring{Performing addition on Church numerals:
\iMbox{\text{succ}} and
\iMbox{(+)}}{Performing addition on Church numerals:  and }}

We can define a \textbf{\textit{successor function}} as

\begin{itemize}
\tightlist
\item
  \iMbox{\text{succ} \ \equiv \ \lambda n f x . \ f \ (n \ f \ x) \equiv \lambda n f x . \ f^{(n+1)} \ x}
\item
  which takes a \ul{Church numeral}
  \iMbox{\displaystyle n \equiv \lambda f x. \ \ f^{(n)} \ x}, and
\item
  returns~\iMbox{n+1}~by adding another application of~\iMbox{f} to it
\end{itemize}

We now apply \iMbox{\text{succ}} to \iMbox{n}, \iMbox{m} times, to
define the \textbf{\textit{addition function}}

\begin{itemize}
\tightlist
\item
  \iMbox{\displaystyle (+) \ \equiv \ \lambda mn. \ m \ \text{succ} \ n \equiv \lambda m n f x. \ f^{(m + n)} \ x}
\item
  so if we treat \ul{Church numerals} as \ul{natural numbers} then
  \iMbox{(+)} is the addition function for \iMbox{\mathbb{N}}

  \begin{itemize}
  \tightlist
  \item
    e.g.~\iMbox{(+) \ 2 \ 3 =_{\beta} 5} are
    \ul{\iMbox{\beta}-equivalent expressions}
  \end{itemize}
\item
  alternatively: \iMbox{(+) \ \equiv \ \lambda mnfx. \ mf (nfx)}
\item
  for \ul{notational convenience} we can use \ul{infix notation},

  \begin{itemize}
  \tightlist
  \item
    when working informally we can just write \iMbox{m + n}
  \item
    but we \ul{know} it stands for \iMbox{(+) \ m \ n} \ul{in actuality}
  \end{itemize}
\end{itemize}

\subsubsection*{\texorpdfstring{Other common arithmetic functions:
\iMbox{(\times)}, \iMbox{\text{pow}}, \iMbox{\text{pred}},
\iMbox{(-)}}{Other common arithmetic functions: , , , }}

Define \textbf{\textit{multiplication}} of \iMbox{m} by \iMbox{n} as

\begin{itemize}
\tightlist
\item
  \iMbox{\displaystyle (\times) \ \equiv \ \lambda m n. \  m \ (n \ +) \ 0}
\item
  can be read as \textit{`add \iMbox{n} to \iMbox{0} \iMbox{m} times'}
\item
  alternatively: \iMbox{(\times) \ \equiv \ \lambda mnf. \ m(nf)}
\item
  for \ul{notational convenience} we can use \ul{infix notation},
  i.e.~\iMbox{(\times) \ m \ n \ \equiv \ m \times n}
\end{itemize}

Define \textbf{\textit{exponentiation}} \iMbox{\displaystyle b^e} as
\ul{Thrush},
i.e.~\iMbox{\mathrm{pow} \equiv \mathrm{T} \equiv \lambda be.eb}

\begin{itemize}
\tightlist
\item
  \iMbox{\text{pow} \equiv \lambda be. eb \ \to_{\beta \eta}^{*} \ \lambda b e f x. \ (f^{(b)})^{(e)} \ x}
\item
  can be read as \textit{`compose \iMbox{f^{(b)}} with itself \iMbox{e}
  times, and then apply that to \iMbox{x}'}
\end{itemize}

Define the \textbf{\textit{predecessor}} function \iMbox{\text{pred}},
where \iMbox{\text{pred} \ 0 = 0} and \iMbox{\text{pred} \ n = n - 1}
for \iMbox{n \geq 1}

\begin{itemize}
\tightlist
\item
  Define helper \ul{``shift-and-increment''}
  \iMbox{\phi \equiv \lambda t. \langle \text{snd} \ t , \ \mathrm{succ} \circ \mathrm{snd} \ t \rangle}

  \begin{itemize}
  \tightlist
  \item
    It maps \ul{pair} \iMbox{\langle m, n \rangle} to
    \iMbox{\langle n,n+1 \rangle}
  \end{itemize}
\item
  \iMbox{\displaystyle \mathrm{pred} \equiv \lambda n. \ \mathrm{fst} \ (n \ \phi \ \langle 0,0 \rangle)}

  \begin{itemize}
  \tightlist
  \item
    This applies \ul{``shift-and-increment''} to
    \iMbox{\langle 0,0 \rangle}, a total of \iMbox{n} times
  \item
    Then selects the \ul{first element} which is \ul{one-behind} the
    \ul{second element}
  \end{itemize}
\end{itemize}

We now apply \iMbox{\text{pred}} to \iMbox{m}, \iMbox{n} times, to
define the \textbf{\textit{subtraction function}}

\begin{itemize}
\tightlist
\item
  \iMbox{\displaystyle (-) \ \equiv \ \lambda mn. \ n \ \text{pred} \ m}
\item
  where \iMbox{(-) \ m \ n} yields \iMbox{m - n} when \iMbox{m > n} and
  \iMbox{0} otherwise
\item
  for \ul{notational convenience} we can use \ul{infix notation},
  i.e.~\iMbox{(-) \ m \ n \ \equiv \ m - n}
\end{itemize}

\subsection*{Pairs and Linked Lists}

We can use \ul{Viero} as our \textbf{\textit{pair constructor}},
i.e.~\iMbox{\mathrm{pair} \equiv \mathrm{V} \equiv \lambda xyz.zxy}, so

\begin{itemize}
\tightlist
\item
  \iMbox{\displaystyle (\mathrm{V} \ x \ y) \equiv \mathrm{pair} \ x \ y}
  represents the pair \iMbox{\langle x,y \rangle}, such that

  \begin{itemize}
  \tightlist
  \item
    applying \ul{Kestrel} \textit{(\iMbox{\mathrm{true}})} will select
    the \ul{first element}, and
  \item
    applying \ul{Kite} \textit{(\iMbox{\mathrm{false}})} will yield the
    \ul{second element}, so
  \end{itemize}
\item
  \iMbox{\text{fst} \equiv \lambda p. \ p \ \mathrm{K} \equiv \lambda p. \ p \ (\lambda xy.x)},
\item
  \iMbox{\mathrm{snd} \equiv \lambda p. \ p \ \mathrm{KI} \equiv \lambda p. \ p \ (\lambda xy.y)}
\end{itemize}

We can then define,

\begin{itemize}
\tightlist
\item
  the \textbf{\textit{empty list}} element
  \iMbox{\text{nil} \equiv \lambda x.\mathrm{K}} and
\item
  a check for it
  \iMbox{\mathrm{isNill} \equiv \lambda x.x(\lambda yz.\mathrm{KI})}
\end{itemize}

With this, we can create \textbf{\textit{linked lists}} as nested
\textbf{\textit{pairs}},

\begin{itemize}
\tightlist
\item
  with the \ul{second} element being either \iMbox{\mathrm{nil}}
\item
  or another pair which follows the same rules
\end{itemize}

So a \textbf{\textit{linked list}} of \iMbox{n} elements
\iMbox{[x_{1}, \dots, x_{n}]} would be encoded as:

\begin{itemize}
\tightlist
\item
  \iMbox{\displaystyle \langle x_{1}, \langle \dots,\langle x_{n}, \mathrm{nil} \rangle \rangle \rangle}
\end{itemize}
